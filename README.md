# My Powerpuff Universe ✦

Hi, I’m Yashaswini. I build software, teach technical ideas, and follow my curiosity. This is my little corner of Townsville, with my projects, experience, and things I’m exploring.

I built it with HTML, CSS, and vanilla JavaScript, and host it on GitHub Pages. The Chemical X bottle, moving clouds, and three-way flights use CSS animations. I used an AI-generated cartoon portrait and character artwork to bring the theme together.

**Come add your superpower!** Pick Heart, Curiosity, or Grit—or type your own. I save your last 12 additions in your browser, so they stay on your device.

I’ve included responsive layouts, keyboard-friendly tabs, project filters, and reduced-motion support. There’s no build step; I preview it with a static server such as `npx serve .`.
