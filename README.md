# Yashaswini Jain — Powerpuff Portfolio

A responsive, Powerpuff Girls inspired personal portfolio with pink, blue and green accents, comic borders, custom CSS illustrations and a Chemical X interaction. Built with semantic HTML, CSS and vanilla JavaScript; no install or build required.

## Run locally

Serve this folder with any static server, for example `npx serve .`, then open its printed local URL. Opening index.html directly also displays the site, although clipboard access may require localhost or HTTPS.

## Content

Includes selected React projects, technical and instructor experience, interests, explorations, education, Humanity’s Last Exam contribution, contact links and the latest available résumé (21 September 2026). Content is carried forward from the user's updated portfolio dated 22 October 2026. Explorations describe interests rather than completed additional projects. Project artwork is illustrative, not a screenshot of the linked application.

Edit index.html for content and project links, style.css for styling, and script.js for filters, copy-email and Chemical X interactions. Replace assets/resume.pdf when updating the résumé. All local links are relative and support subdirectory hosting such as GitHub Pages.

## Deploy

Static hosting: publish the repository root with no build command. For GitHub Pages, choose Settings → Pages → Deploy from a branch → main / root. For Vercel, import the repository, choose Other, leave Build Command empty and publish the root directory.

## Accessibility

Semantic sections and headings, skip link, visible keyboard focus, accessible filter buttons, live result count and interaction feedback, responsive layout, and prefers-reduced-motion support. Google Fonts are optional; local sans-serif fallbacks are provided.
